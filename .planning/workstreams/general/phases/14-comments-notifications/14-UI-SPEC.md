## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage                                                                    |
| ----- | ----- | ------------------------------------------------------------------------ |
| xs    | 4px   | Gap between author name and timestamp, icon-to-label gap                 |
| sm    | 8px   | Gap between avatar and comment body, action-button gaps, badge padding   |
| md    | 16px  | Panel horizontal padding, gap between threads, notification item padding |
| lg    | 24px  | Panel header/footer vertical padding, section separation                 |
| xl    | 32px  | Empty-state vertical padding                                             |
| 2xl   | 48px  | Not used in this phase                                                   |
| 3xl   | 64px  | Not used in this phase                                                   |

Layout specifics:

- Comments Sheet: `side="right"`, width `w-full sm:max-w-md` (448px max); header, scrollable body, sticky composer footer.
- Replies: indented 32px (xl) left with a 1px `border-l` guide; one level only (D-07).
- Notification popover: width 360px (`w-[360px]`, max `calc(100vw - 32px)`), list max-height 400px, scroll inside.
- Bell trigger and comments button use icon `Button` `size="icon"` (36px visual) with `min-h-11 min-w-11` hit area on touch.

Exceptions: touch targets 44px (icon buttons); avatar sizes 32px (comment author) and 24px (resolved stub); unread badge 16px tall circle, 20px min-width, offset -4px top/right. All are multiples of 4; the 1px `border`/`border-l` hairlines are excluded from the scale.

## Typography

Three font sizes (12, 14, 16) and two weights (400, 600) across the whole phase.

| Role                                                                                 | Size | Weight         | Line Height |
| ------------------------------------------------------------------------------------ | ---- | -------------- | ----------- |
| Body (comment text, notification text, composer)                                     | 14px | 400 (regular)  | 1.5         |
| Label (author name, buttons, "Show resolved", stub text)                             | 14px | 600 (semibold) | 1.5         |
| Meta (timestamps, counts, badge number, char counter, helper text)                   | 12px | 400 (regular)  | 1.5         |
| Heading (panel title "Comments", popover title "Notifications", empty-state heading) | 16px | 600 (semibold) | 1.2         |

Notes: comment bodies render as plain text with `whitespace-pre-wrap break-words`; no markdown, no autolinking (research Pitfall 8). Badge digits use 12px at semibold (600); this stays within the 4 sizes and 2 weights.

## Color

Uses existing theme tokens from `app/globals.css`; no new colors introduced.

| Role            | Value                                                            | Usage                                                                                               |
| --------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Dominant (60%)  | `--background` oklch(1 0 0) light / oklch(0.145 0 0) dark        | Sheet and popover surface, composer background                                                      |
| Secondary (30%) | `--muted` / `--card` / `--accent` (oklch 0.97 light, 0.269 dark) | Resolved stub background, unread notification row tint, reply guide, hover states, "[deleted]" stub |
| Accent (10%)    | `--primary` #7e10b2 (purple)                                     | See reserved list below                                                                             |
| Destructive     | `--destructive` oklch(0.577 0.245 27.325)                        | Delete comment confirmation action only                                                             |

Accent reserved for:

1. The "Post comment" / "Reply" submit button (primary variant)
2. Unread-count badge on the bell (`bg-primary text-primary-foreground`)
3. Unread dot (8px) on unread notification rows
4. Count badge on the comments toolbar button while the Sheet is open (`Badge` with `className="bg-primary text-primary-foreground"`; closed state uses `variant="secondary"`)
5. Focus ring on the composer (default `ring` token)

Not accent: resolve/unresolve buttons (ghost), delete (ghost, turns destructive text only on hover and in confirm dialog), "Show resolved" toggle (outline/ghost), timestamps, links.

Muted text: `text-muted-foreground` for timestamps, "[deleted]" copy, resolved stub text, helper text.

## Component Contracts

Visual anchors: Comments Sheet primary focal point is the composer (sticky footer) together with the oldest unresolved thread at the top of the body. Notification popover focal point is the unread rows (tinted, with primary dot), which sort first visually by tint against read rows.

### Comments toolbar button (NoteContent header row, next to Share)

- Ghost icon+label button: `MessageSquare` 16px + count in a `Badge variant="secondary"` (hidden when 0). Visible to all roles including `view`. `aria-label`: "Comments, {n}". Cap display at "99+".
- Toggles the Sheet; initial state derives from `?comments=1` (and `&c=<commentId>` scrolls to and briefly highlights that comment for 2s using `bg-accent`).
- Visitor pages (`SharedNoteView`, `PublicNoteView`): same button placed in the page header area; open state local only.

### Comments Sheet

- Header: Heading "Comments" with count, close X (built into Sheet), and a "Show resolved" toggle (`Switch` + label, off by default, D-06) beneath the title with an Separator.
- Body: threads ordered by creation time ascending (oldest first, matches research A5). Each thread = root comment + flat replies oldest-first (D-07).
- Footer (sticky): composer.
  - Signed in: `Textarea` (min 3 rows, auto-grow to 8 rows), char counter "{n}/2000" in Meta size shown only past 1800, submit button right-aligned. Cmd/Ctrl+Enter submits. Button disabled when body is empty after trim or over 2000 chars; shows spinner while pending.
  - Anonymous (visitor pages): composer replaced by a muted Card with text "Sign in to comment" and a `SignInButton` wrapping a `Button variant="outline"` (not accent).
- Loading: 3 `Skeleton` rows (32px avatar circle + two text lines). Query `null` mid-view (revoked token): render existing `SharedUnavailable` content in place of the body.

### Comment item

- 32px `Avatar` (initials fallback via existing `getInitials`), author name (Label), relative time (Meta; `Intl.RelativeTimeFormat` locale-aware, full date in `title`/Tooltip), body (Body).
- Actions row (Meta-size ghost buttons, 28px visual / 44px hit via padding): "Reply" (root only), "Resolve" (root only, shown to signed-in users), "Delete" (only when `canDelete`). Actions hidden for anonymous viewers. Actions appear on hover/focus on desktop and are always visible on touch.
- Reply composer: inline under the thread, same `CommentComposer` in compact mode (2 rows), "Discard reply" (ghost) + "Reply" (primary) buttons; Esc also discards.
- Deleted root with replies: renders "[deleted]" stub in `text-muted-foreground italic`, no avatar name (generic avatar), replies remain (D-09). Localized: "Comment deleted".

### Resolved thread (D-06)

- Hidden by default. With "Show resolved" on, renders a single-line stub: `Check` icon, "Resolved thread by {name}" truncated first line of root body, Meta timestamp, and an "Unresolve" ghost button. Stub background `bg-muted`, 8px radius, 8px/16px padding. Click on the stub row does NOT expand; only unresolve is offered (keeps to D-06 one-line contract). Replies are not shown while resolved.
- Resolving a thread shows a toast "Thread resolved" with an "Undo" action. No toast library is installed (package.json has no sonner), so add `sonner` via `npx shadcn add sonner` (shadcn official registry) and mount `<Toaster />` once in the locale layout. All error handling in this phase uses `toast.error(...)`.

### Delete confirmation

- `AlertDialog` for deleting any comment. Destructive action button uses `--destructive`.

### Notification bell (Header.tsx, right cluster before sign-in buttons / user area; authenticated only; not on visitor pages, D-14)

- Ghost icon `Button` with `Bell` 20px; badge top-right: unread count, hidden at 0, "99+" at 100; `aria-label`: "Notifications, {n} unread".
- Popover (align end, 360px): header row with Heading "Notifications" and "Mark all read" ghost button (disabled when 0 unread, `CheckCheck` icon). List of up to 20 items.
- Notification row: 32px `Avatar` of actor, text (Body) "{actor} commented on "{title}"" or "{actor} replied to your comment on "{title}"" (title truncated to 1 line, actor semibold), Meta relative time under it. Unread rows: `bg-accent` tint plus 8px primary dot at the right; read rows: plain background. Whole row is a button/link: click marks that item read then navigates to `/notes/{noteId}?comments=1&c={commentId}` and closes the popover (D-15). Opening the popover marks nothing read.
- Keyboard: popover items reachable by Tab, Enter activates, Esc closes, focus returns to bell.
- Loading: 3 skeleton rows. Real-time: badge and list update reactively with no refresh affordance.

## Interaction and Accessibility

- Sheet and Popover use Radix focus trap/return; Sheet title is the heading (`SheetTitle`), with `SheetDescription` visually hidden.
- Bell badge and toolbar count are announced via `aria-label`; new-comment arrival updates the list with `aria-live="polite"` on the thread container.
- All icon-only buttons have `aria-label`; color is never the only unread indicator (unread is conveyed by dot, tint, and "Unread" `sr-only` text).
- Contrast uses existing theme tokens (primary #7e10b2 on white passes AA for badge text with `primary-foreground`).
- Mobile (<640px): Sheet is full width; popover width clamps to viewport minus 32px.
- Dark mode: inherits theme tokens; no per-component overrides.
