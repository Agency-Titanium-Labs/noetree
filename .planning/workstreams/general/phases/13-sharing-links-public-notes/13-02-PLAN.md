## Trust Boundaries

| Boundary                                         | Description                                                    |
| ------------------------------------------------ | -------------------------------------------------------------- |
| anonymous browser -> getSharedNote/getPublicNote | Unauthenticated callers supply token / noteId strings          |
| signed-in browser -> updateSharedNoteContent     | Caller supplies token + content; identity from Clerk JWT       |
| owner browser -> management mutations            | Supplies noteId; authorization derived server-side             |
| Convex action -> internal mutation               | Token generated in Node runtime, persisted by internalMutation |

## STRIDE Threat Register

| Threat ID | Category               | Component                                                | Disposition | Mitigation Plan                                                                                                                        |
| --------- | ---------------------- | -------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| T-13-05   | Spoofing               | token guessing on getSharedNote                          | mitigate    | 256-bit randomBytes(32) token, exact by_token index lookup, min length 43 enforced in insertLink                                       |
| T-13-06   | Tampering              | anonymous write via edit token                           | mitigate    | updateSharedNoteContent calls getUser first and throws UNAUTHENTICATED before token lookup; test with valid edit token and no identity |
| T-13-07   | Tampering              | edit link patching other fields (parent, owner, title)   | mitigate    | patch object restricted to content + updated_at; test asserts other fields unchanged                                                   |
| T-13-08   | Information Disclosure | owner/emails/childNotes leaked by anonymous projections  | mitigate    | Whitelisted return objects; Object.keys assertions in tests                                                                            |
| T-13-09   | Information Disclosure | revoked-vs-never-existed oracle                          | mitigate    | Both return null (queries) / LINK_INVALID (mutation)                                                                                   |
| T-13-10   | Elevation of Privilege | edit/view-role shared users creating links or publishing | mitigate    | requireManage owner/admin only; tests for NOT_ALLOWED                                                                                  |
| T-13-11   | Denial of Service      | oversized content or malformed JSON via edit link        | mitigate    | 500000-char cap (CONTENT_TOO_LARGE) and JSON.parse validation (INVALID_CONTENT)                                                        |
| T-13-12   | Information Disclosure | token in logs                                            | mitigate    | No console.log/console.error with tokens; anonymous query uses ctx.auth directly                                                       |
| T-13-13   | Repudiation            | no editor attribution on link edits                      | accept      | D-11 defers attribution to Phases 14-15                                                                                                |
| T-13-SC   | Tampering              | npm/pip/cargo installs                                   | accept      | No packages installed (node:crypto built-in)                                                                                           |
