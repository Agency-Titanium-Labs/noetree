## Trust Boundaries

| Boundary                                    | Description                                                                        |

| browser -> Convex content mutations         | `content` and note id are attacker-controlled; caller identity comes from ctx.auth |
| note owner's subscription -> history window | Tier must come from DB, never from the client                                      |

## STRIDE Threat Register

| Threat ID | Category               | Component                 | Disposition | Mitigation Plan                                                                                                                                                              |
| --------- | ---------------------- | ------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-15-01   | Tampering              | content write paths       | mitigate    | All three mutations route through writeNoteContent; static "single write path" test fails if any patch writes content directly                                               |
| T-15-02   | Spoofing               | lastEditedBy / authorId   | mitigate    | userId passed to writeNoteContent is always the server-resolved `user._id`; no userId argument added to any function                                                         |
| T-15-03   | Elevation of Privilege | getOwnerWindow            | mitigate    | Tier derived from note.owner -> users.tokenIdentifier -> subscriptions.by_clerkUserId; client never supplies tier; tests for Free/Premium owner and cross-tier collaborators |
| T-15-04   | Information Disclosure | getHistoryAccessOrNull    | mitigate    | Only owner/admin/edit via getUserPermission; view share, edit-link-only, stranger, anonymous -> null; tested                                                                 |
| T-15-05   | Denial of Service      | version growth            | mitigate    | 5-minute gate, unchanged-skip and empty-skip bound inserts per note; content row capped by existing MAX_CONTENT_LENGTH / 1 MB doc limit                                      |
| T-15-06   | Tampering              | comments isolation (D-14) | mitigate    | Helper file imports nothing from comments; invariants comment in schema                                                                                                      |
