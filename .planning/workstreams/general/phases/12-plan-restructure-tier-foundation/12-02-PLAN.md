<objective>
Create the `scripts/` toolchain for this phase's Stripe-side work, and implement + test the one-time Premium price setup: rename the existing Stripe Product from "Pro" to "Premium" and create the two new Price objects (6.99 EUR/month, 59 EUR/year).

Purpose: Stripe `Price.unit_amount` is immutable — the new Premium pricing (PLAN-08) can only exist as new Price objects, and Stripe Checkout's line-item label (PLAN-07's "Stripe Checkout shows Premium" criterion) comes from `Product.name`, which IS mutable. Both are one-time live-billing operations that must be reproducible, idempotent, and runnable by an operator against test mode before live mode.

Output: `scripts/stripeOps.ts` (pure functions, dependency-injected Stripe client), `scripts/stripeOps.test.ts` (fake-client unit tests, zero network), `scripts/setup-premium-prices.ts` (CLI), `scripts/tsconfig.json`, three `npm run stripe:*` entries, and the new env vars documented in `.env.example`.

This plan does NOT run anything against Stripe. Execution is plan 12-06.
</objective>
