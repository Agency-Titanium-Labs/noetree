## 6. Aggregated tech debt

- Retention and lifecycle: no retention cron for aiRuns, aiRateLimits (17 L5) and aiTreeBatches (20 L4); no GDPR cascade for aiSuggestions, aiSuggestionLimits, aiSuggestionDaily, autocompletePrefs (21 L6); rejected beginRun calls not edge-rate-limited (17 M4).
- Tree (20): applied notes bypass writeNoteContent (no first version snapshot, no embedding scheduling until first edit, L12); unread outline count not shown in the UI; no Premium or rate gate on applyAiTree (accepted).
- Autocomplete (21): 1 credit lost if the view is destroyed during the accept round trip (L1, L2); text visible before accept (honest-client model, bounded by daily cap 1000, tune with suggestionStats after launch); uses client textBefore rather than assembleContext (own note only, by design); touch devices without a fine pointer get no suggestions.
- Links (22): large-note reads in scan (L1); concurrent analyses of one note guarded only by UI (L4); listLinkedNotes silent take(100); vectorSearch mocked in tests (L10); gateway retry and backoff not hardened (L5).
- Chat (19): hand-written SSE framing (mitigated by useChat transport test); nested lists and tables flattened on Insert; 19-REVIEW finding L9 never identified or addressed; preview can differ from sent context if the note changes (Refresh link).
- Metering (17): past_due keeps its balance until month rollover (M6); canceled Premium clamps to 30 (product copy undecided); abort before first token refunded (accepted F-04).
- VAT (23): no refund path; WR-01 unfixed; getSplitConfig public (accepted); VAT depends on a per-deployment Convex env var and silently falls back to 0 on an invalid value (logged).
- Ops: dev/staging and prod Convex deploy, backfill, per-env test purchase, key rotation, AI Gateway credits decision (Claude vs free-tier model); AI_GATEWAY_API_KEY is also needed in each Convex deployment for the links action.
