## Typography

Exactly 4 sizes, 2 weights (regular 400, semibold 600).

| Role                                                    | Size              | Weight | Line Height |
| ------------------------------------------------------- | ----------------- | ------ | ----------- |
| Body (row text, table cells, buttons)                   | 14px (`text-sm`)  | 400    | 1.5         |
| Label (column headers, card captions, badges, footnote) | 12px (`text-xs`)  | 600    | 1.5         |
| Heading (card values, empty-state heading, row title)   | 20px (`text-xl`)  | 600    | 1.2         |
| Display (page `h1`, same as My listings)                | 30px (`text-3xl`) | 600    | 1.2         |

Notes: row title in the purchases list is Body size at weight 600 (not Heading). Summary card values (gross, commission, net, count) use Heading. Money uses `tabular-nums`. Footnote and "Sent to Stripe" label use Label size, weight 400 allowed only via `text-muted-foreground` color, not a third weight (render at 600 only for column headers/badges; footnote text stays 400 which is the Body weight).

## Layout and Interaction Contract

### Shared page shell (D-03)

`<div className="mx-auto max-w-3xl space-y-8 px-6 pt-12">` containing `h1` (Display) and content. `useHeaderConfig({ title })` as in My listings. Page is client component, queries skipped until signed in.

### Sidebar (D-01, D-02)

Two items appended after `listings`: Purchases (`ShoppingBag`), Sales (`Wallet`). Always visible to signed-in users. Labels from `Sidebar.purchases` / `Sidebar.sales`.

### /purchases (HIST-01)

- List of rows, each a `Card` (padding `p-4`, gap `gap-4`), newest `paidAt` first, page size 10, "Load more" outline button when `status === "CanLoadMore"`.
- Row layout: left column = title (Body 600, truncate, one line), below it meta line (Label, muted): `{PriceLabel} · {paid date}`; mode badge right of title on desktop, under title on mobile. Right column = actions (stacked full-width on < `sm`, inline on `sm+`).
- Actions: `Open note` (primary Button, link to `/notes/{openNoteId}`) shown only when `openNoteId` exists and delivery is not failed; `View listing` (outline, link to `/marketplace/{listingId}`) always shown. When `delivery === "failed"`: replace Open note with an inline `Alert variant="destructive"` (icon `TriangleAlert`) with the delivery problem copy; View listing still shown. When copy deleted: Open note hidden, no notice.
- Date: `Intl.DateTimeFormat(locale, { dateStyle: "medium" })`. If `paidAt` is missing, omit date and the separator.
- Loading: 3 `Skeleton` rows (h-20 rounded-xl). No receipt, invoice, or refund affordances (D-07).

### /sales (HIST-02)

Order top to bottom:

1. **Summary grid** (D-08): `grid gap-4 grid-cols-2 md:grid-cols-4` of 4 `Card`s: Total gross, Total commission, Total earned (net; this is the "running total", D-09), Sales count. Each card: Label caption on top (muted), Heading value below. Net card gets no extra emphasis beyond a `ring-1 ring-border` match to others (keep uniform).
2. **Payout panel**: one `Card` full width, `flex` row (stacked on mobile): left = "Payout account" Label caption + Connect status badge (from `getMyConnectStatus`), right = `Open Stripe dashboard` primary Button with `ExternalLink` icon, rendered only when status is active. Pending state shows `Loader2` spinning and disabled button; error shows inline destructive text under the button (`role="alert"`). No `finally` reset on success (redirects).
3. **Sales list** (D-12): at `md+` a shadcn `Table` with columns: Date, Listing, Gross, Commission (amount plus rate, e.g. "2,00 EUR (20%)" with rate in muted Label), Net, Payout ("Sent to Stripe"). Money columns right-aligned, `tabular-nums`. Below `md`: stacked Card per sale (title + date on first line, then 3-line definition list Gross / Commission (rate) / Net, then payout label). Page size 20, "Load more" outline button. Sorted newest `paidAt` first. No buyer identity anywhere (D-13).
4. **Footnote** (Label size, muted): states that totals reflect all paid sales and that bank payout timing follows Stripe's schedule (D-10). Always visible when at least one sale exists.

- Totals come from `sales.getMyTotals`, independent of loaded pages. While loading, cards show `Skeleton` blocks (h-16). Zero state values render as formatted zero, not skeleton.
- Percent format: `Intl.NumberFormat(locale, { style: "percent", maximumFractionDigits: 2 })` on `commissionRateBps / 10000`.
- Label strictly "Total earned", never "balance" or "available".

### States matrix

| State                 | /purchases                                                                         | /sales                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Loading first page    | 3 skeleton rows                                                                    | Skeleton cards + skeleton rows                                                                      |
| Empty                 | Empty-state panel (muted card, centered, `py-16`, lucide `ShoppingBag` 32px muted) | Cards show zeros; list area replaced by empty-state panel (`Wallet` icon); payout panel still shown |
| Error (query failure) | `Alert variant="destructive"` above list                                           | same                                                                                                |
| Signed out flash      | render nothing/skeleton, never error                                               | same                                                                                                |

### Accessibility

Table uses semantic `<table>` with `<th scope="col">`; stacked cards use `<dl>`. Status never conveyed by color alone. All icon-only affordances absent (all buttons carry text). Visible focus ring from shadcn defaults. Loading buttons set `aria-busy`. Sales/purchases lists wrapped in `<ul>`/`<table>` with an accessible name via `aria-labelledby` on the h1.
