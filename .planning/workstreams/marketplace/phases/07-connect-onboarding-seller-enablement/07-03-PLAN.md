<objective>
Build the second, Connect-scoped webhook path end to end: a new Next.js route
`app/api/webhooks/stripe-connect/route.ts` verifying its own `STRIPE_CONNECT_WEBHOOK_SECRET`, a new
Convex dispatcher action `processConnectWebhookEvent`, and the `.env.example` documentation for the
new secret.

Purpose: This closes 07-RESEARCH.md Pitfall 2 — connected-account events are delivered ONLY to an
endpoint registered with `connect: true` and are signed with a DIFFERENT secret than the platform
endpoint. Wiring `account.updated` into the existing single dispatcher would result in total silence.
Two fully separate routes/secrets make the boundary structurally impossible to blur.
Output: new route + dispatcher action + tests + env documentation.
</objective>
