<objective>
Create the `createConnectOnboardingLink` server action — the single code path behind all three D-03
CTA labels ("Become a seller", "Resume onboarding", "Update details"). It authenticates via Clerk,
looks up the caller's existing Connect account, creates a Stripe Express account only when none
exists, records the inert account id in Convex, always mints a fresh Account Link, and redirects.

Purpose: CONNECT-01. D-02 requires going straight to Stripe's hosted flow with no in-app dialog; D-07
requires never persisting or reusing an Account Link URL, which sidesteps link expiry entirely and
removes the need for any "link expired" error state.
Output: one server action plus its unit tests.
</objective>

       comment: this write stores an inert account id only so a second click cannot orphan a duplicate

<threat_model>

## Trust Boundaries

| Boundary                        | Description                                                 |
| ------------------------------- | ----------------------------------------------------------- |
| browser → Next.js server action | The `locale` argument is fully attacker-controlled          |
| Next.js server → Stripe API     | Holds `STRIPE_SECRET_KEY`; creates a real connected account |
| Next.js server → Convex         | Authenticated with the caller's own Clerk→Convex token      |

## STRIDE Threat Register

| Threat ID | Category                 | Component                                               | Disposition | Mitigation Plan                                                                                                                                                                                                                  |
| --------- | ------------------------ | ------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-07-13   | Spoofing                 | `clerkUserId` written into Stripe account metadata      | mitigate    | Sourced only from `auth()`'s `userId`; the action takes no user identifier argument. That metadata is later trusted by `upsertFromStripeAccount`'s insert path, so a client-supplied value would be an account-linking primitive |
| T-07-14   | Tampering                | Open redirect / URL injection via the `locale` argument | mitigate    | `locale` checked against `routing.locales`, falling back to `routing.defaultLocale`, before interpolation into `refresh_url`/`return_url`; unit test asserts a traversal string collapses to `/en/settings`                      |
| T-07-15   | Elevation of Privilege   | Onboarding return trip treated as proof of capability   | mitigate    | The action performs no post-return state write and reads no `searchParams`; only `upsertFromStripeAccount` (plan 02) can set capability flags. Acceptance criterion greps for zero `searchParams` references                     |
| T-07-16   | Information Disclosure   | Leaking the Clerk→Convex token or Stripe key in logs    | mitigate    | `console.error` calls carry a static message plus the caught error only; the token variable is never logged                                                                                                                      |
| T-07-17   | Denial of Service / cost | Duplicate Express accounts from repeated clicks         | mitigate    | `accounts.create` runs only when `getMyConnectStatus` returns no `stripeAccountId`, and the id is persisted immediately via `recordPendingAccount`; unit test asserts zero `accounts.create` calls for a returning seller        |
| T-07-SC   | Tampering                | npm/pip/cargo installs                                  | accept      | No new packages installed in this plan (07-RESEARCH.md Package Legitimacy Audit: zero new dependencies this phase)                                                                                                               |
